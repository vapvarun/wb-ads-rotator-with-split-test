# WB Ad Manager

Show your own ads, AdSense and affiliate links anywhere on your WordPress site, rotate and split-test them, and track what works. The free plugin covers everything on these pages. WB Ad Manager Pro adds selling ad spots to advertisers; its pages live in the [Pro repository](https://github.com/vapvarun/wb-ad-manager-pro/tree/main/docs/website).

Requires WordPress 6.9 or newer and PHP 8.1 or newer.
