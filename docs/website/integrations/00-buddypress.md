# BuddyPress Integration

When BuddyPress is active, WB Ad Manager registers extra placements automatically - no configuration needed. If BuddyPress is not active, an admin notice on the Ads list says so, and these placements stay hidden.

## Placements added

| Placement | Where it renders |
|-----------|------------------|
| BuddyPress Activity | Injected into the activity stream between posts |
| Directory - Before Members | Top of the members directory |
| Directory - After Members | Bottom of the members directory |
| Directory - Before Groups | Top of the groups directory |
| Directory - After Groups | Bottom of the groups directory |

## Use it

1. Confirm BuddyPress is active.
2. Create or edit an ad.
3. In the **Placements** metabox, check the BuddyPress positions you want.
4. Publish.

Targeting, scheduling, and rotation work the same as for any other placement - see [Targeting and Scheduling](../features/30-targeting-and-scheduling.md).
