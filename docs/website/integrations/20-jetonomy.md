# Jetonomy Integration

When the Jetonomy community plugin is active, WB Ad Manager adds seven placements for Jetonomy spaces and topics. All seven are free-plugin features. Jetonomy v1.3.0 or later is required.

## Placements

| Placement | Where it renders |
|-----------|------------------|
| Sidebar Top | Top of the Jetonomy sidebar |
| Sidebar After About | Between the About card and the next widget (space pages) |
| Sidebar Bottom | Bottom of the Jetonomy sidebar |
| After Topic Body | Directly under the topic body, before replies |
| Before Replies | Above the first reply |
| Between Replies | Every N replies |
| After Replies | Below the last reply |

## Between-reply frequency

The "Between Replies" position has two extra options:

- **Show after** - the reply number to anchor on (default 5).
- **Repeat every** - if enabled, repeat every N replies instead of once.

## Use it

1. Install and activate Jetonomy (v1.3.0+).
2. Edit an ad, check the Jetonomy positions you want.
3. Publish.

If Jetonomy is not active, the Ads list shows a dismissible notice pointing to it.
