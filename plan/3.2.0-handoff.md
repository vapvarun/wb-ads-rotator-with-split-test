## 3. How to work on this code

- **Fix at the root, in a worktree** on a branch from `origin/3.2.0`. Never
  `git add -A` in a worktree (its `vendor/` is a symlink the ignore rule misses); add
  files by path.
- **Commits carry no AI attribution trailers.** Check `git log -1 --format=%B`.
- **Tests:** Pro's tests live in this repo under `tests/pro/`.
  `WBAM_RUN_PRO_TESTS=1 vendor/bin/phpunit --testsuite=free` (and `--testsuite=pro`),
  against the WP test library from `bin/install-wp-tests.sh`, on its own database.
  Code that runs an SDK money call (`START TRANSACTION`/`COMMIT`) commits the test's
  transaction: insert fixtures directly or delete them in `tear_down`.
- **Gates before landing:** both suites green, Pro `bin/release-gate.sh` (lint,
  PHPStan, Plugin Check, bundled SDK diff), Free `bin/plugin-check-gate.sh` (0 errors),
  `bin/check-hooks-documented.sh` in each repo.
- **Moving a card:** comment with the commits, root cause, proof and retest steps, then
  move it to Ready for Testing. QA works from the cards (cards-only communication).
- **Dates:** store UTC, show and pick in the site time zone (Settings > General).
- **Words:** follow `docs/standards/glossary.md`: Balance and Add funds, never
  "Credits" or "Wallet" on screens; a seller's item uses the owner's label through
  `Settings_Helper::get_classifieds_label()`. `tests/pro/test-vocabulary-wave6.php`
  enforces it.
- **Settings:** plug-and-play. Rare technical options become filters; business
  controls stay settings.

  or removes a surface.

- Pro bundles the Wbcom Credits SDK **1.9.4** (`libs/wbcom-credits-sdk`, stamped in
